# Averon Academy — Week 4: Dynamic Post Explorer

A responsive web application built with vanilla HTML5, CSS3, and modern JavaScript (`async/await`, `fetch API`, array methods, and dynamic DOM manipulation).


 How to Run This Project

Clone or Download this repository to your local machine.
Open the project folder in Visual Studio Code.
Locate the `week-04/` directory.
Run locally:
   - The easiest way is using the Live Server extension in VS Code.
   - Right-click `index.html` and select "Open with Live Server".
   - Alternatively, you can double-click `index.html` to open it directly in your default web browser.
